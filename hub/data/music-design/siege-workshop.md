# Music design: Siege Workshop

Game: `siege-workshop` (roadmap)  
Status: **recommended**  
Archetype: medieval-siege  
Setting: medieval siege rig test yard

Recommendation: Building and testing a siege rig on a wall fits heavy taiko war drums and brass.

## Siege Workshop - main theme (`siege-workshop-A`)

Status: prompt_ready | Vocals: none | BPM: 118

**Style prompt**

```
Medieval castle siege orchestral and folk-warfare score, clean mix, dry studio recording, minimalist frequency separation, martial, ancient and thunderous, medieval siege rig test yard atmosphere, Strings, Brass, Snare, Timpani, Harpsichord, Bagpipes, 118 BPM, strict quantize, steady 4/4 rhythm, memorable repeating melodic motif, instrumental
```

Stems requested: Brass, Snare, Strings, Timpani
