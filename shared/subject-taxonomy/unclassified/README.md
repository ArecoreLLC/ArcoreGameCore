# Unclassified image set

This directory is reserved for reference images that are intentionally outside the current taxonomy. They are evaluation inputs for discovery, unknown-label preservation, and future profile proposals.

Images placed here should retain their source prompt, generation date, model, and a short subject description in a sidecar JSON file. Do not add an image to the canonical taxonomy until its labels and construction parts have been reviewed.

The 200-image evaluation set is being assembled in numbered batches. `batch-001.json` records the first four unknown subject families, represented in the corresponding generated reference sheet. Each four-panel sheet is a seed batch; later batches will add new subjects and controlled variants such as viewpoint, lighting, occlusion, and material changes.
