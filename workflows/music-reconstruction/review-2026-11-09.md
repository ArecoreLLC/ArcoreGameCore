# Workflow maintenance review — 2026-11-09

Scope: code and retained evidence review, not a new auditory assessment. The
consumer has progressed through thirteen reconstruction revisions. The latest
saved eleven-song summary has one pass, ten warnings and no failures, with all
entries still marked not auditioned. First-pass native reloads, catalog records
and Drive receipts must stay scoped to the revision they actually checked.

## Maintained sequence

1. Freeze the source, tool/model/bank identities and declared licenses.
2. Separate and retain aligned stems; compare the full recording when stems bleed.
3. Build a full-mix tempo/song-map proposal with local pacing and ambiguity retained.
   Export tempo-mapped MIDI without changing the source seconds timeline.
4. Build reviewed instrument/note candidates and render with the chosen articulation.
   Keep Performance/Quality drums and source-supported hybrid variants identifiable.
5. Check rendered attack delay and dynamics. Record every timing or level change,
   including gain automation absent from plain MIDI, then remeasure the final audio.
6. Validate every song; distinguish pass, warning, failure and insufficient evidence.
   Empty selections and validation failures must produce unsuccessful batch exits.
7. Audition original, rendered and hybrid mixes on one visible timeline, with
   separate vocal and drum comparisons. Preserve comments, creative exceptions,
   final-file hashes and unresolved issues. Theory remains advisory.
8. Reopen current native projects, verify delivery encodes and publish the exact
   approved revision. Separate review-only delivery from game release acceptance.

## Improvements to prioritize

- **Timing evidence:** nearest-neighbor attack matching can reuse an attack for
  several notes. Signed medians can hide opposite errors. Require one-to-one
  matches, coverage, absolute-error tails and an independent envelope check before
  accepting a retimed candidate. Sparse evidence is inconclusive, not a clean pass.
- **Drum completeness:** label short passages with actual kick/snare/hat/fill events
  and assess missing hits as well as doubles. Do not retune thresholds merely to
  make an automatic batch green.
- **Dynamics:** compare each part's attack, sustain and release to source evidence;
  level riding can conceal a wrong instrument or note. Preserve dry renders and
  gain automation so the edit remains explainable and reproducible.
- **Reproducibility:** use explicit revision configuration rather than import-time
  mutation, and cache attack compensation by full synthesis identity. Test song-order
  independence and interrupted-run recovery.
- **Instrumentation:** distinguish playable library support from catalog presence.
  The consumer now has a Rust SFZ adapter and a retained sfizz comparison; this is
  not proof of complete SFZ opcode, articulation or streaming support in every app path.
  Consult actual renderer tests and library licenses before choosing a mapping.
- **Tagging:** the new local CLAP tool supplies hypotheses, not confirmed instrument
  identities. Require full-file coverage, source/model hashes, pinned dependencies,
  absent-instrument controls and human approval. Relative scores depend on which
  stems are included in the comparison group.
- **Handoff:** bind current project-load, audio-quality and listening results to
  the delivered hashes. Track Drive receipt and SoundCore catalog status separately;
  neither certifies musical quality or game playback.

No universal quantization, key correction or theory-conformance gate is introduced.
Preserve original vocals and expressive timing unless a reviewed correction is intended.

Reusable checks: decode actual MIDI tempo events rather than reuse the writer's
time conversion; check expected tracks and note counts before reporting timing
error; never reuse an observed event for several targets; retain both source-time
origin and output hashes. Treat bass leaps, sustained overlap, bar-pattern changes,
chord membership and missing drum classes as review cues until checked against
source evidence. Do not apply harmonic checks to drum pitches or force 4/4/grid
assumptions on unknown meter. Shared-detector agreement is not independent evidence.

The local-model priority is a separate full-mix beat/downbeat estimator, then
