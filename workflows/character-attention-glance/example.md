# Worked example: ShammyVerse (November 2026)

ShammyVerse: Poofy (`poofy_reactions.gd`) and Plumpy on his shoulder (`plumpy_shoulder_reactions.gd`) turn toward dolphin leaps, gull landings, cannons and stones. The first version had no rest and the butterflies and bubbles near Island One pinned Poofy's head permanently; the 2.6 s glance and 3.5 s rest fixed it.

The game code stays in the ShammyVerse repository (`game/scripts/`, `Design/Iterations/world-life-v001/DESIGN_LOG.md`).
The GameCore component was generalised from it and checked by the headless component test.
