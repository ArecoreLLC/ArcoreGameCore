# Worked example: ShammyVerse (November 2026)

ShammyVerse: candy-cane gates every 26 m on the Sweet Sweet to Gumdrop Canyon route give the ship a 60 % speed burst that decays over about three seconds, with marshmallow snow in the lane ("Through the peppermint winds and the marshmallow snow!", `voyage_life.gd`).

The game code stays in the ShammyVerse repository (`game/scripts/`, `Design/Iterations/world-life-v001/DESIGN_LOG.md`).
The GameCore component was generalised from it and checked by the headless component test.
