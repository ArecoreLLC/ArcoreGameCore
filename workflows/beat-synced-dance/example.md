# Worked example: ShammyVerse (November 2026)

ShammyVerse: gumdrop bears dance in circles and stomp up sand puffs on Sweet Sweet and Friendship Isle, a puffer drum circle bounces, and Plumpy's Teacup party drums tap on the beat (`shore_life.gd`, `festive_life.gd`, `teacup_party_life.gd`). Tempos from `song_beats.gd` range from 94 to 143 BPM. The world-life test checks stomps fire on the beat at the dance circle.

The game code stays in the ShammyVerse repository (`game/scripts/`, `Design/Iterations/world-life-v001/DESIGN_LOG.md`).
The GameCore component was generalised from it and checked by the headless component test.
